# Optional MediaPipe browser perception

MediaPipe Tasks Vision 0.10.32 and the Google MediaPipe pose-lite, hand,
face and selfie-segmenter version-1 artifacts are optional downloads. Runtime
source: https://github.com/google-ai-edge/mediapipe . License: Apache-2.0;
the full license is retained in MediaPipe-APACHE-2.0.txt. Model provenance:
https://developers.google.com/edge/mediapipe/solutions/vision . Exact upstream
artifact URLs, sizes and checksums are in the perception pack assets.json.

The runtime and model bytes are not redistributed in the Genereti archive.
The runtime CDN files are verified against the installed pinned npm package.
No code was copied from Underscores or Artist–Model Studio for this implementation.
Their semantic streams and gesture authoring approaches informed the design.
