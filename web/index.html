Start live to transform the animated sketch. Try a prompt, drag the sketch influence, or choose Draw and sketch directly.

Camera / SketchCam: enable camera, then choose a device. Use Image remix for color and composition, or enable MediaPipe pose for a moving silhouette.

Composite: at supported sizes, run SDXS sketch and SD-Turbo Canny as two image branches. Set an optional independent Canny shape source in More controls, then blend the branches. A palette reference in Post-processing transfers overall colors. This costs about two model passes.

Space pauses generation. Output opens a clean view for performance. Save PNG embeds prompt and settings metadata; Save scene packages source, optional guides, palette reference, generated outcome, and metadata. Copy scene makes a labeled board.

The FPS counter counts new AI frames. These are one-step image models applied to a live stream; they can flicker and distort anatomy.
