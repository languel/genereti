# Student quickstart

Install Genereti using the [README instructions](../README.md#student-getting-started). You do not need models, a model server, npm, or another extension for these examples.

1. Open **Workflows → Genereti** or **Templates → genereti**.
2. Start with **ꘇ-Performance-Timeline** and follow its lesson. Toggle the timeline with **Alt+Shift+T**.
3. Try **ꘇ-Livecode-Shader-Buffers**, **ꘇ-Livecode-P5-Pipeline**, and **ꘇ-Livecode-Audio-Visual**.
4. Start sound explicitly on `mod.output`; begin at a low volume.
5. Save your own copy with a new name. Updates preserve edited saved demos.

GPU texture examples need a browser with WebGPU. Camera/screen examples require explicit permission and a user action. MIDI/OSC and the assistant are optional connections, not required services.

See [all demos](workflows.md), [shortcuts](shortcuts.md), and [platform support](platform-support.md). Old AI demos are no longer automatically installed; inference is moving to [GeneretiCore](https://github.com/languel/genereticore).
