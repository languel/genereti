# Archived generator and standalone experiments

Historical source preserved for migration to [GeneretiCore](https://github.com/languel/genereticore). This is not part of the supported Genereti framework, Registry package, or automatic demo installation. Scripts and documents describe the old layout and may require migration before running. Use the private development checkout for the existing working generator until GeneretiCore has a tested replacement.

The original relative tree is preserved here for engine code, native/bridge packs, conversion scripts, standalone web experiments, tests and inference workflows. Model weights and local captures are not included. Do not install archived packs alongside the supported package.
