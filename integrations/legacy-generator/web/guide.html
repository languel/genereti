Connect Genereti to your creative tools

Genereti runs its image generator on an Apple silicon Mac and publishes the latest frame locally. Its p5.js and ComfyUI source nodes can also run independently on a PC with ComfyUI.

TouchDesigner

Add a Web Render TOP with http://127.0.0.1:8765/output. Use a custom 512 × 512 resolution, turn off “Only Update when Loaded,” and enable “Cook Always.”

p5.js

Open http://127.0.0.1:8765/p5 for the live stage. The GeneretiClient browser module is available at /genereti-client.js.

ComfyUI

Install the included node packs with scripts/install_comfy.sh and restart ComfyUI. Open Genereti-Live-Inputs.json for doodle, camera, and window sources, or Genereti-p5-Sketch.json for an interactive sketch connected to the generator.

The source-only workflows Genereti-Input-Sources.json and Genereti-p5-Source.json preview and save their source on a PC without calling the Core ML backend.
