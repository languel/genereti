Make an image move.

Start live to transform the animated sketch. Try a prompt, drag the sketch influence, or choose Draw and sketch directly.

Shapes · Excalidraw: edit shapes, paths, rotation and colors inside the fixed dashed artboard. The canvas is the workspace; drag the Generated frame to arrange live output. The Genereti button opens/closes the model sidebar. Save/Open drawing uses editable .excalidraw files; Save scene also includes the drawing. Pan/zoom does not change the generator crop.

Camera / SketchCam: enable camera, then choose a device. Use Image remix for color and composition, or enable MediaPipe pose for a moving silhouette.

SDXS guide mixer: sum independently weighted image/sketch, edge, depth and uploaded pose guide residuals into one SDXS generation pass. All guides use the released sketch weights; depth and pose transfer are experimental. Dedicated SDXS Canny/depth-trained weights from the paper are not included. Start at 512 px, sketch 0.65, edges 0.55, depth and pose zero.

Composite: at supported sizes, run SDXS sketch and SD-Turbo Canny as two image branches. Set an optional independent Canny shape source in More controls, invert either guide independently, then blend the branches. A palette reference in Post-processing transfers overall colors. This costs about two model passes.

Guide strength: sketch influence is a learned ControlNet signal, not how much of the original pixels are preserved. Use Image remix · SD-Turbo when you want latent image-to-image transformation. Canny, depth, pose, and sketch guide polarity can be inverted separately in More controls.

Upscaler feedback: choose 2–4 passes and a loop blend to feed each downsampled Real-ESRGAN result into the next pass. Select Keep source size to explore surface changes without enlarging the image. The pass count multiplies upscaler time.

Alt + Space pauses generation; Space pans the canvas. Output opens a clean view for performance. Save PNG embeds prompt and settings metadata; Save scene packages source, optional guides, palette reference, generated outcome, and metadata. Copy scene makes a labeled board.

The FPS counter counts new AI frames. These are one-step image models applied to a live stream; they can flicker and distort anatomy. Choose 512 px for SDXS text/sketch when available; the installed Canny/Turbo composite is 256 px. Post-processing includes emboss, palette and level controls, brightness/contrast/saturation, recursive upscaling, sharpening, and resampling.
