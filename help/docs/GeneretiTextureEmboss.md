# ꘇ top.emboss

Directional Sobel luminance gradient mapped around bias (default 0.5). Angle in degrees, strength, mix with source; alpha preserved. Produces a relief-style shading effect. It does not estimate geometric or metric scene depth.

Model-free WebGPU in Live mode; queued PyTorch implementation. Uses shared preview, output window, overlay and backdrop controls. No model downloads.
