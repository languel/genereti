# ꘇ top.colormap

Normalize luminance using low/high, optionally invert, map through grayscale, heat, cool, rainbow or a five-anchor approximation of viridis. Mix blends with the original RGB. Alpha unchanged. High must exceed low. For custom palette images use top.lookup.

Model-free WebGPU in Live mode; queued PyTorch implementation. Uses shared preview, output window, overlay and backdrop controls. No model downloads.
