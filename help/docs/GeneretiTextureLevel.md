# ꘇ top.level

Normalize black/white input levels, apply brightness gain, contrast around 0.5, saturation, gamma, then output black/white. Defaults are identity. Gamma above 1 brightens midtones. White must exceed black. Alpha is unchanged.

Model-free WebGPU in Live mode; queued PyTorch implementation. Uses shared preview, output window, overlay and backdrop controls. No model downloads.
