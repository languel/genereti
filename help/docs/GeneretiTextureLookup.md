# ꘇ top.lookup

Connect a horizontal color ramp IMAGE to lookup. Map source luminance or each RGB channel separately at normalized row. Interpolates between LUT texel centers; row also interpolates. Mix blends with the source. Source alpha stays unchanged; LUT alpha is ignored. For built-in ramps use top.colormap.

Model-free WebGPU in Live mode; queued PyTorch implementation. Uses shared preview, output window, overlay and backdrop controls. No model downloads.
