# ꘇ top.edge

Sobel, Scharr or four-neighbor Laplacian on alpha-weighted luminance. Strength scales edge magnitude; threshold remaps the remaining range; invert flips it. Boundaries clamp to edge. Source alpha is preserved.

Model-free WebGPU in Live mode; queued PyTorch implementation. Uses shared preview, output window, overlay and backdrop controls. No model downloads.
