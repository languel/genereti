# Lesson quick reference

A lesson is a guided sequence, while a node reference is a reminder you can read at any time.

Edit the lesson’s JSON document, then use its local Run button to start the guide. Each step has a title, text, optional hint and optional node target/check or recorded actions.

- **◎** focuses the target tool.
- **?** reveals that step’s hint.
- **✓** checks the learner action or finishes the guide.
- **▷** opens the lesson-authoring walkthrough from this reference.

The hint button inside a lesson is separate from the **? Quick reference** button on a node. Queue returns the lesson document; it does not start the walkthrough.
